# 6 个月，成为 AI 工程师 · Become an AI Engineer in 6 Months

[English below](#english)

## 中文说明

这是一个纯静态的学习指南网站，基于 [DeRonin_ 在 X (Twitter) 上分享的 AI 工程师 6 个月路线图](https://x.com/DeRonin_/status/2033587293064204349) 整理与扩展而成。

### 本站特点

- **全站中英双语**：以简体中文为主，辅以英文专业词汇与对照。
- **项目驱动学习**：每个月度模块均配置一个明确的“里程碑项目”（Milestone Project），强调“手脑并用，重在建造”。
- **极简典雅设计**：
  - 背景色：`#FAF7F1`（温润纸质调）
  - 文字色：`#2A2A28`（水墨黑灰）
  - 点缀色：`#A8894F`（哑光金）
  - 全站字体：`Noto Serif SC`（宋体/衬线体）
  - 单一 CSS 文件 (`styles.css`)，无框架，极简静谧。

### 目录结构

```
.
├── index.html   # 主页面 (HTML)
├── styles.css   # 单一 CSS 样式文件
└── README.md    # 项目说明文档
```

## English Description

A minimal, pure static learning website turning [DeRonin_'s 6-Month AI Engineer Roadmap](https://x.com/DeRonin_/status/2033587293064204349) into a hands-on, bilingual study hub.

### Highlights

- **Bilingual Content**: Simplified Chinese primary, English secondary.
- **Milestone-Driven**: Each month culminates in a hands-on project — *build it, don't just read it*.
- **Calm & Minimal Aesthetics**:
  - Background: `#FAF7F1` (Warm paper)
  - Text: `#2A2A28` (Ink gray)
  - Accent: `#A8894F` (Matte gold)
  - Font: `Noto Serif SC` (Serif typography)
  - Pure HTML + single `styles.css` file without external frameworks.
