Learning Resources · 24 Weeks 资料库

M1：代码基本功

Week 1 · Python

  • [必读] CS50P：哈佛 Python 入门 —— 哈佛的 Python 入门课
  • [选读] Python for Everybody（Coursera，可免费旁听） —— 零基础友好的 Python 入门课
  • [选读] Python 官方教程 —— 查漏补缺的手册
动手：写一个 CLI 小工具（记账本/天气查询），数据存 JSON 文件
我的笔记 →

Week 2 · Git 与终端

  • [必读] Learn Git Branching —— 可视化练分支，半小时上手
  • [选读] Pro Git（免费书） —— Git 权威指南
  • [选读] MIT Missing Semester —— 终端与工具链，CS 必修课
动手：每个项目都建 GitHub 仓库，从第一天养成习惯
我的笔记 →

Week 3 · JSON / API / HTTP / 异步

  • [必读] MDN：HTTP 概述 —— 先搞懂 GET/POST 和状态码
  • [选读] requests 官方文档 —— Python 发请求就用它
  • [选读] Real Python：async/await —— 异步一次讲透
动手：调用免费的 Open-Meteo 天气 API，把返回的 JSON 整理干净
我的笔记 →

Week 4 · SQL / Pandas / FastAPI

  • [必读] FastAPI 官方教程 —— 半天搭出第一个 API
  • [选读] SQLBolt —— 交互式学 SQL，边练边学
  • [选读] Kaggle Pandas 课程 —— 数据处理上手最快
动手：跑通一个 FastAPI 应用，浏览器打开 /docs 玩一圈
我的笔记 →

M2：LLM 应用开发

Week 5 · 提示词基本功

  • [必读] Anthropic 提示词工程文档 —— 官方指南，先看它
  • [选读] OpenAI 提示词指南 —— 对照看两家的思路差异
  • [选读] PromptingGuide.ai —— 提示词技巧的百科全书
动手：为同一个真实任务写 5 版提示词，对比输出差异
我的笔记 →

Week 6 · 结构化输出 + 工具调用

  • [必读] Anthropic Tool Use 文档 —— 工具调用官方指南
  • [选读] OpenAI Structured Outputs 指南 —— 让模型稳定吐 JSON
  • [选读] Instructor —— Pydantic 结构化输出神器
动手：做一个发票解析器，返回结构化的 Python 对象
我的笔记 →

Week 7 · 流式输出 + 对话状态

  • [必读] Simon Willison：流式 LLM API 原理 —— 流式讲得最透的一篇
  • [选读] Anthropic Streaming 文档 —— 官方流式接口文档
  • [选读] OpenAI 对话状态管理 —— 多轮对话的上下文怎么存
动手：写一个终端多轮聊天机器人，带 /reset 和每轮 token 计数
我的笔记 →

Week 8 · 成本 / 延迟 / 失败处理 / 注入防御

  • [必读] OWASP LLM01：提示词注入 —— 安全风险必读
  • [选读] OpenAI Tokenizer —— 花钱之前先算 token
  • [选读] Tenacity —— 重试退避，失败处理的标配库
动手：给你的应用加上重试、超时和降级，别让一次坏输出搞崩全场

M3：RAG

Week 9 · Embeddings + 切块

  • [必读] Weaviate：RAG 切块策略 —— 切块是 RAG 的隐形胜负手
  • [选读] Stack Overflow：直观理解 Embeddings —— 先建立直觉
  • [选读] OpenAI Embeddings 指南
动手：embed 20 个句子，做一个最近邻搜索
我的笔记 →

Week 10 · 向量数据库 + 元数据过滤

  • [必读] Chroma —— 本地原型最快，上手零摩擦
  • [选读] Pinecone 学习中心 —— 托管向量库的系统教程
  • [选读] pgvector —— 已经在用 Postgres 就选它
动手：把 50–100 页文档索引进 Chroma，写一个 top-5 查询函数
我的笔记 →

Week 11 · 重排 + 检索质量

  • [必读] Pinecone：提升检索质量 —— 语义漂移、切块边界问题的解法
  • [选读] Cohere Rerank 文档 —— 两阶段检索的第二阶段
动手：给 Week 10 的检索加上 rerank，对比 top-5 质量变化
我的笔记 →

Week 12 · 幻觉控制 + 引用 + 框架

  • [必读] LlamaIndex RAG 入门 —— M3 用 LlamaIndex
  • [选读] Anthropic Citations —— 让回答带上出处
  • [选读] LangChain RAG Agent —— M4 转 LangChain 做 Agent
动手：做一个"和你的文档聊天"的 FastAPI 应用，10–20 个 PDF，回答带引用

M4：Agent 与评测

Week 13 · Agent 循环 + 工具选择

  • [必读] Anthropic：Building Effective Agents —— Agent 必读，先读它
  • [选读] OpenAI 实用 Agent 指南（PDF）
  • [选读] LangChain Academy：LangGraph 入门
动手：不用框架，纯手写一个 Agent（raw API + 3 个工具）
我的笔记 →

Week 14 · 状态管理 + 失败重试

  • [必读] LangGraph 状态管理 —— TypedDict 状态与检查点
  • [选读] Real Python：LangGraph —— 实战教程
动手：给 Week 13 的 Agent 加上最大迭代次数和工具级重试
我的笔记 →

Week 15 · 什么时候不用 Agent + 工作流模式

  • [必读] Anthropic Workflow Patterns —— 链式、路由、并行、编排四种模式
  • [选读] Simon Willison：设计 Agentic Loops
记住：3 个固定的 LLM 调用，永远比"可能调 3 次"的 Agent 更快更便宜更好调
动手：做一个 3 步内容流水线——抽事实→并行生成推文+帖子+摘要→打分选最优

Week 16 · 评测 + 成功指标

  • [选读] Promptfoo —— prompt 回归测试

M6：选方向，成为能上场的人

三个方向三选一，Week 21–Week 23 各对应一个方向，Week 24 通用。

Week 21 · 方向一：AI 产品工程师（想快速进初创公司选它）

  • [必读] Google People + AI Guidebook —— AI 产品的 UX 设计指南
  • [选读] Vercel AI SDK —— 前端 AI 应用的最快路径
  • [选读] Streamlit —— Python 一把梭做出 demo
动手：本月交付 2–3 个完整可演示的项目，部署上线
我的笔记 →

Week 22 · 方向二：应用 ML / LLM 工程师（想走更硬核的技术路线选它）

  • [必读] OpenAI 微调指南 —— 先搞清何时该微调、何时不该
  • [选读] Unsloth —— 高效微调工具
  • [选读] Ollama —— 本地跑开源模型做实验
动手：用 LoRA 微调一个小模型，对比微调前后效果，算清成本账

Week 23 · 方向三：AI 自动化工程师（想立刻给企业做东西选它）

  • [必读] n8n 文档 —— 工作流自动化平台
  • [选读] Temporal —— 可靠的工作流编排
动手：做一个端到端的线索筛选系统——导入线索→LLM 逐个调研→打分排序→写个性化 outreach→记入表格/CRM（能卖钱的那种）

Week 24 · 作品集打磨 + 出发

  • 整理 6 个月的项目：每个都有 README、能跑的 demo、清晰的文档
  • GitHub 主页收拾干净，项目置顶
  • 公开分享学习过程（X / LinkedIn）：教是最好的学，声誉带来机会
  • 别等"准备好了"：有能跑的项目就可以开始投简历、接单。市场奖励 ship 的人，不奖励完美主义者
